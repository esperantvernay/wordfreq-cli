# WordFreq CLI

> A modern command-line tool built in Python to fetch and analyze word frequencies.

## 📋 Features

- Dependency management and packaging via **uv**
- Command-line interface powered by **Click**
- HTTP requests handling via **Requests**

## 🚀 Installation & Build

Ensure you have [uv](https://github.com/astral-sh/uv) installed on your system.

1. Clone the repository:
   ```bash
   git clone [https://github.com/esperantvernay/wordfreq-cli.git](https://github.com/esperantvernay/wordfreq-cli.git)
   cd wordfreq-cli

2. Install dependencies and set up the environment:
    ```bash
    uv sync

3. Usage and running
    ```bash
    uv run wordfreq-cli --help

4. testing 
    ```bash
    uv run pytest
